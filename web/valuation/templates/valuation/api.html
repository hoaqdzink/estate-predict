API

API trả về JSON, không cần xác thực, chỉ dùng cho mục đích học tập và thử nghiệm.

GET /api/districts/?city=Hà Nội

Danh sách quận/huyện của một thành phố. city: {{ cities|join:" | " }}.

POST /api/predict/

Dự báo giá. Thân yêu cầu là JSON. Thêm ?explain=0 để bỏ phần giải thích SHAP (nhanh hơn).

Ví dụ
curl -X POST http://127.0.0.1:8000/api/predict/ \
  -H "Content-Type: application/json" \
  -d '{"city": "Hà Nội", "district": "Cầu Giấy", "house_type": "Nhà trong hẻm",
       "area_m2": 50, "road_width_m": 3, "floors": 5}'

Kết quả gồm: price_billion_vnd, interval_95, price_per_m2_million_vnd, location (khoảng cách, tiện ích 2 km), stacking (dự báo của 5 mô hình con và trọng số), explanation (SHAP), warnings.

Lỗi trả về mã 400 kèm {"error": ..., "fields": {...}}; thiếu tệp mô hình trả về 503.
